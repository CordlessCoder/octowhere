OCTOWHERE

SIMULATOR

The firmware's screens, drawn by its own code and running in your browser. Touch the round screen as you would the device. The controls stand in for its keys and sensors, and every reading is synthetic. Run several devices to see them find each other over a simulated radio, each on the firmware's own mesh code.
